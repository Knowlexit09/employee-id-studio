# Repository status

This GitHub repository contains an offline browser demo, documentation, and a **Laravel application overlay**. It is not a full Laravel installation. Copy the overlay onto a newly installed Laravel 13 project following the root README. The backend has not been runtime-tested end-to-end or deployed. Do not use real employee data in the demo or in GitHub.

The Attendance & Payroll repository remains separate and is not connected by a live API. See `INTEGRATION_CONTRACT.md` for the planned integration boundary.
